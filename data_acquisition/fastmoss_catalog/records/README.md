## 数据处理与已发现问题

1. **5 件商品跨页重复。** 唯一商品表采用同 ID 最近一次读取的记录，并保留全部 occurrences；不叠加重复销量。原始观察记录完整保留。重复原因待确认，本次不能视为同一时刻完整前 100 名的快照。
2. **3 件疑似非服装。** 标题显示优惠券、衣架、包袋，标记 suspected_non_clothing，暂不纳入服装候选。其余 92 件只是未被本次标题筛查标记，尚未逐件详情验收。
3. **12 件三日销售额展示值高于总销售额。** 原值未修改，口径、同步或估算原因待核实；不能直接当作可信趋势信号。
4. **26 件未展示佣金比例，31 件展示价格范围。** “-”转为 null，不当作零；区间保留两端，不把最低价当作全部 SKU 的实际成交价。
5. 数值字段由页面文字解析得到。包含“万”的数值仅是缩写展示值换算，精确程度未提高；商家实际交易真实性、估算误差与市场覆盖均未独立验证。
6. 前三行数字排名单元格为空，保留空值；list_slot_number 是页码和行号推导的位置。不能把它说成额外读取到的排名。
7. 页面只展示“$”；币种代码未独立确认，currency_code 留空。美国筛选下推断为美元是合理推断，未升级为已核实字段。
